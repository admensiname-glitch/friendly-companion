# Política de Segurança

## Reportar uma vulnerabilidade

Não publique detalhes de uma possível falha em uma issue pública. Para relatar uma vulnerabilidade, entre em contato privadamente com os mantenedores pelo canal de contato privado disponível no perfil/organização do repositório ou use o recurso **Report a vulnerability** em **Security → Advisories** quando estiver habilitado.

Inclua, se possível, o impacto, os passos para reproduzir e uma sugestão de correção. Não inclua dados pessoais de estudantes, tokens, senhas ou outros segredos no relato.

## Escopo e resposta

A prioridade é proteger contas, dados acadêmicos, mensagens e informações de perfil dos estudantes. Os mantenedores devem confirmar o recebimento, avaliar a gravidade, limitar a exposição e preparar uma correção antes de divulgar detalhes técnicos exploráveis.

## Uso responsável

Não acesse, altere, extraia ou compartilhe dados de outros usuários. Testes devem usar contas e dados controlados pelo responsável pelo projeto.
